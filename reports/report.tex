\section{Введение}

\subsection{Постановка проблемы и цель исследования}
Исходная задача создания интеллектуальной системы для реконструкции архитектурных объектов требует, в качестве фундаментального этапа, точной диагностики текущего состояния поверхности.
Целью данного исследовательского проекта является проверка гипотезы о возможности выявления значимых паттернов в изображениях поверхностей с помощью методов снижения размерности и неконтролируемого обучения, что составляет основу для последующего построения эффективных моделей поддержки принятия решений в системах мониторинга.

\subsection{Гипотеза}

Основная гипотеза: Методы снижения размерности и кластеризации позволяют выявить скрытые, статистически значимые факторы в пространстве признаков изображений, которые объективно разделяют состояния «поврежденная поверхность» и «неповрежденная поверхность». Эти факторы могут служить основой для построения эффективных признаковых описаний в системах автоматического мониторинга.

Дополнительная гипотеза: Внутри однородной категории «поврежденная поверхность» существуют различные подтипы дефектов (например, различающиеся по морфологии или контрасту), которые образуют обособленные подкластеры в пространстве признаков и могут быть выявлены методами неконтролируемой кластеризации.

\subsection{Задачи исследования}
Для достижения поставленной цели в работе последовательно решаются следующие задачи:

\begin{itemize}
\item Выбор и предварительный анализ набора данных изображений поверхностей с повреждениями и без них.

\item Проведение разведочного анализа данных для оценки статистических различий между классами и визуального понимания природы дефектов.

\item Разработка и применение конвейера для извлечения информативных признаков, преобразующих изображения в формат, пригодный для алгоритмов.

\item Применение методов снижения размерности (PCA, t-SNE) для анализа структуры данных, визуализации и проверки разделимости основных классов.

\item Проверка возможности выделения устойчивых подклассов внутри категории поврежденных изображений с помощью алгоритмов кластеризации.

\item Количественная оценка и содержательная интерпретация полученных результатов, формулировка выводов о подтверждении или опровержении выдвинутых гипотез.

\end{itemize}

\subsection{Используемые методы}

\subsubsection{Снижение размерности}

\begin{itemize}
\item \textbf{Метод главных компонент (PCA – Principal Component Analysis):}
Линейный метод, находящий новые ортогональные оси (главные компоненты) в данных, которые максимизируют сохраняемую дисперсию. Первая компонента соответствует направлению наибольшей изменчивости данных. Цель применения: 1) Резкое сокращение числа признаков (с 85 до ~10-50) для снижения вычислительной сложности и "шума"; 2) Интерпретация: анализ весов в первых PC показывает, какие исходные признаки вносят наибольший вклад в разделение данных.

\item \textbf{t-SNE (t-distributed Stochastic Neighbor Embedding):} Нелинейный метод, оптимизирующий представление данных в пространстве низкой размерности (обычно 2D) для сохранения локальных расстояний между точками. Цель применения: Визуальная качественная оценка структуры данных. Ожидаемый результат: Если признаки информативны, то на графике t-SNE изображения с трещинами и без них образуют визуально разделимые скопления (кластеры).
\end{itemize}

\subsubsection{Методы кластеризации}

\begin{itemize}
\item \textbf{Иерархическая агломеративная кластеризация (Agglomerative Clustering):}
Алгоритм "снизу вверх", начинающий с того, что каждая точка является отдельным кластером, и последовательно объединяющий наиболее близкие пары кластеров. Близость определяется выбранной метрикой расстояния и методом связи (linkage): ward (минимизация дисперсии), average, complete. Цель применения: 1) Проверка основной гипотезы: применив алгоритм ко всему датасету без учета меток, ожидаем получить разделение, близкое к исходным классам "трещина"/"нет трещины". 2) Исследование иерархической структуры данных с помощью дендрограммы.

\item \textbf{K-Means:} Итеративный алгоритм, минимизирующий сумму квадратов расстояний от точек до центроидов их кластеров. Требует априорного задания числа кластеров k. Цель применения: Используется в методе "локтя" (Elbow Method) для эмпирической оценки оптимального числа кластеров k по точке изгиба графика "инерция (within-cluster sum of squares) – k".

\item \textbf{DBSCAN (Density-Based Spatial Clustering):} Алгоритм, основанный на плотности, формирующий кластеры как области высокой плотности точек, разделенные областями низкой плотности. Выделяет выбросы (шум). Цель применения: Автоматическое обнаружение кластеров произвольной формы в данных о трещинах, без предположения об их сферичности или заранее заданном количестве.
\end{itemize}

\subsubsection{Метрикa оценки качества кластеризации}
\textbf{Силуэтный коэффициент (Silhouette Score):} Оценивает, насколько похож объект на свой собственный кластер (когезия) по сравнению с другими кластерами (сепарация). Диапазон значений от -1 до 1. Интерпретация: Значения >0.5 указывают на сильную кластерную структуру, около 0 – на перекрывающиеся кластеры, <0 – на возможную неверную кластеризацию. Это основная метрика для сравнения методов и оценки разделимости.

\section{Практическая часть}

\subsection{Предварительный анализ данных}

Для выборки из 100 изображений каждого класса рассчитано распределение значений пикселей. Установлены статистически значимые различия между классами по средней яркости (175.7 для Negative vs 164.0 для Positive) и контрастности (стандартное отклонение: 11.1 для Negative vs 31.8 для Positive). Это количественно подтвердило визуальные наблюдения и обосновало возможность автоматического разделения.

\begin{itemize}
    \item Статистику интенсивности (7 признаков).

    \item Признаки HOG (первые 20 компонент).
    \item Градиентные признаки (4 признака на основе фильтров Собеля).
\end{itemize}

\subsection{Кластеризация}

\subsubsection{Кластеризация всего датасета}
Применение Agglomerative Clustering к данным после PCA выявило, что первое крупное разделение на 2 кластера практически полностью соответствует исходным классам. Это подтверждает, что выявленная PCA структура является объективной и воспроизводимой.

Этот вывод подтверждается самым высоким средним значением по первой главной компоненте (PC1 = 848.21), которая, как показал PCA-анализ, вносит наибольший вклад в дисперсию данных и сильно коррелирует с признаками контраста.

\textbf{Кластер 1} (444 изображения, ≈3\% трещин): Представляет собой практически чистые поверхности без повреждений. Доминирование этого класса в выборке соответствует сбалансированности исходного датасета.

\textbf{Кластер 2} (275 изображений, ≈97\% трещин): Включает изображения с менее выраженными или более тонкими трещинами. Среднее значение PC1 для этого кластера существенно ниже (269.66), чем у Кластера 0, что указывает на меньший визуальный контраст дефектов относительно фона.

Наличие подобной градации имеет практическое значение для систем мониторинга, так как позволяет не только детектировать факт повреждения, но и проводить первичную оценку его серьезности.

\section{Выводы}

\subsection{Гипотезы}
\textbf{Основная гипотеза подтвердилась полностью}. Методы снижения размерности и кластеризации успешно выявили фундаментальные латентные факторы, лежащие в основе различия между повреждённым и неповреждённым состоянием бетонных поверхностей.

\textbf{Дополнительная гипотеза подтвердилась частично}. Внутри категории "трещины" были обнаружены признаки внутренней структуры, однако не в виде множества подклассов, а в виде градации по степени выраженности. Agglomerative Clustering выделил два устойчивых подкласса повреждений, интерпретируемых как: кластер "Явные/контрастные трещины" (высокие значения PC1) и кластер "Слабые/низкоконтрастные трещины" (средние значения PC1).
Это разделение, выявленное на всём датасете, указывает на существование непрерывного спектра повреждений, который алгоритм разбил на две наиболее однородные группы, что имеет ценность для приоритизации.

\subsection{Ограничения исследования}
Несмотря на достигнутые результаты, работа имеет ряд ограничений, определяющих границы применимости выводов. Наиболее весомое ограничение - исследование проводилось на одном конкретном датасете. Результаты могут не обобщаться на данные, полученные в принципиально иных условиях (например, с дронов или при другом освещении).

Методологическое ограничение: Выбор числа кластеров в Agglomerative Clustering, несмотря на опору на дендрограмму, частично остается субъективным решением исследователя. Альтернативные методы (например, DBSCAN) показали низкое качество на этих данных.

\section{Заключение}
В рамках данного исследовательского проекта был успешно реализован и протестирован конвейер анализа изображений поверхностей на основе методов снижения размерности и кластеризации. Работа подтвердила, что данный подход позволяет не только эффективно отделять повреждённые поверхности от неповреждённых, выявляя скрытые, но статистически значимые паттерны, но и проводить внутреннюю градацию трещин по степени их визуальной выраженности. Таким образом, достигнута основная цель исследования — доказана принципиальная возможность и практическая целесообразность использования предложенного набора методов для решения задач автоматизированного мониторинга состояния строительных конструкций, что формирует прочную основу для разработки более сложных и специализированных диагностических систем.
